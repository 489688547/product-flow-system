# ADR：公司网页采集迁移到专用浏览器运行时

## 状态

已被 `2026-07-25-existing-chrome-extension-first.md` 取代，2026-07-25。

真实验收发现公司日常 Chrome 已有可复用登录态，而专用 Profile 会重复要求登录并增加运行入口。
本 ADR 保留为历史记录；专用浏览器实现继续作为多账号隔离和故障回退，不再是默认主链路。

本决策取代“MV3 扩展承担长任务执行”的主链路设计，但不推翻
`2026-07-24-douyin-preauthenticated-chrome-collection.md` 中关于已登录 Chrome、
固定来源、只读采集、凭据留在公司 Mac 和人工验证不绕过的安全边界。

## 背景

现有网页采集由 MV3 扩展轮询本机 Bridge，并在 Service Worker 中完成开页、等待页面、
点击导出和等待下载。真实运行证明该链路能完成抖店和快麦采集，但长期稳定性受以下因素影响：

- MV3 Service Worker 会被 Chrome 回收，长任务可能失去运行上下文。
- 解压安装的扩展依赖本地源码目录，目录变化或扩展未重载会导致页面脚本不可用。
- 页面日期控件、按钮和结构变化会使固定脚本失败，且远程诊断证据不足。
- 浏览器、扩展、本机 Bridge 和本机处理器同时参与任务生命周期，失败归属不够清晰。

公司 Mac 可以长期保留一个可见的专用采集 Chrome，并允许员工在登录、验证码、扫码或设备确认时
人工处理，因此无需继续让扩展承担长时间编排。

## 决策

### 运行时

- 公司 Mac 的后台采集服务启动并管理非默认 `user-data-dir` 的持久 Chrome Profile。
- 不同登录账号使用独立 Profile；同一账号下的多个店铺可以共用 Profile，但执行前必须核对店铺 ID。
- Chrome 保持可见，用于员工处理登录和人工验证；采集服务重启后复用同一 Profile 登录态。
- Chrome 只执行必须在已登录页面内完成的短操作：
  - 打开代码登记的官方页面；
  - 判断登录或人工验证状态；
  - 核对店铺名称和稳定店铺 ID；
  - 选择任务业务日期；
  - 点击官方导出并返回下载事件；
  - 在没有官方报表时读取固定白名单指标。
- Chrome 不解析文件、不决定口径、不保存批次、不持有 D1 或 Pages 凭据，也不直接写数据库。

### 本机采集服务

- 承担所有耗时和可恢复任务：等待报表、监控下载稳定、哈希归档、文件解析、字段校验、
  分块上传、幂等、重试、断点恢复、诊断保留和健康上报。
- 任务阶段和本地检查点一一对应；服务或 Chrome 重启后从最后安全阶段恢复。
- 页面失败时只在公司 Mac 保存登记报表页面的加密截图和脱敏结构指纹；加密密钥由 macOS
  Keychain 管理，诊断保留 7 天后自动删除。诊断文件、绝对路径和页面内容不上传 D1。
- 原始官方文件继续只保存在公司 Mac。

### 云端边界

- 继续复用 `/api/platform/v1/web-collection` 的 runner、store、job、run、cursor、lease 和 notification。
- 云端只下发已登记的 `provider + store/account + resource + businessDate + targetEnvironmentVersion`；
  不下发任意 URL、脚本、选择器或数据库标识。
- 本机只通过受控 ingest API 上传标准事实；Pages Functions 校验设备、任务租约、目标环境版本、
  批次完整性和幂等后，使用服务端 D1 binding 写入。
- 成功、失败、等待人工和页面变化都保留同步记录；只有完整批次成功才推进可信游标。

### Provider 适配器

- 抖店、快麦、巨量千川等平台使用同一浏览器监管、任务执行、文件处理和入库框架。
- 页面 URL、日期控件、下载动作、白名单指标、报表 schema 和稳定错误码留在 Provider adapter。
- 未登记 Provider、资源、域名、页面或字段 fail closed。
- 首期只迁移抖店四类资源；稳定后迁移快麦，巨量千川仍需单独完成数据口径和真实页面验收。

## 异常与人工协作

- 临时网络、报表生成慢和下载超时在任务截止时间内最多自动重试 3 次。
- 登录、验证码、扫码、滑块、设备确认和店铺不匹配进入 `waiting_human`，不消耗自动重试次数。
- 页面结构或报表字段变化停止对应资源入库，保留上一可信批次。
- 任务必须有阶段截止时间；过期任务转为可恢复终态，不允许永久显示“采集中”。
- 每日 07:30 前仍未就绪时，数据同步页显示平台、Profile、店铺、资源、设备、恢复动作和安全错误摘要。

## 迁移与回滚

1. 新运行时先以独立执行器版本接入现有控制面。
2. 同一任务只能由插件或专用浏览器中的一个执行器领取。
3. 使用已成功批次做回归，再完成最新业务日四资源真实采集。
4. 专用浏览器连续稳定运行 7 天后，MV3 扩展退出自动领取，仅保留短期回滚。
5. 回滚时停用专用浏览器执行器并恢复插件领取；已完成批次、原始归档和同步记录不删除。

## 结果

采集稳定性不再依赖 MV3 长任务生命周期和解压扩展目录。系统仍依赖平台页面与官方报表，
因此 Provider adapter 必须保留字段变化检测、人工恢复和文件导入兜底。公司 Mac 关机、睡眠或未登录
仍会影响采集，但会形成明确的设备或人工协作记录，不再表现为无期限运行中。
