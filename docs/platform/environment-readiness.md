# 环境与生产数据

统一查看测试、预览和生产环境的数据库、钉钉及外部平台能力，并为授权账号提供受审计的生产数据修正入口。

## 环境状态

页面只显示变量名、绑定名和表结构是否存在，不展示任何密钥值。阻断项必须在发布验收前修复；警告项不会阻止核心系统运行，但会影响对应平台能力。

表结构检查按数据库 binding 汇总后以最多 50 个表名一批查询，避免能力目录增长后超过 SQLite 的参数上限。
任一批查询失败时保持 fail-closed，不把部分结果误报为完整就绪；固定站验收必须使用当前版本的
readiness 接口复核全部批次。

如果生产 readiness 故障同时阻断自动 `main → dev` 回同步 smoke，先在 `dev` 通过普通修复 PR、
Cloudflare 测试静态站和 ECS 测试 API 验收，再用不绕过质量门禁的合并 PR 恢复 `main` 祖先关系；
之后仍只允许通过 `dev → main` 发布修复。不得直接推送 `dev`、伪造部署 commit 或把临时上传视为交付。

## 生产数据规则

标准本地开发只运行本地 SQLite 沙箱。`npm run seed:sandbox` 初始化结构，`npm start` 启动本地前端与 API；生产令牌、远程数据库和生产 Provider 凭据均不进入该运行时。共享测试使用 `https://test.deshan-tiyes.cn` 与 `https://api-test.deshan-tiyes.cn`，生产验收使用 `https://deshan-tiyes.cn`。

“解锁 15 分钟生产写入”属于独立的生产数据运维修复网关；通过该网关写入时仍检查版本、保存写前快照并记录审计。

## 外部平台边界

生产数据库写入权不等于钉钉、快麦或其他平台的真实操作权。真实外部动作只能由固定测试或生产域名上的真实会话进入对应路由，再次通过角色、目标范围和提供商权限；localhost 或数据库权限不会放行。
