# 研发待办交互设计

## 页面

页面顶部显示待澄清、待开发、开发中、待验收和已阻塞计数。主操作为“和 AI 总助讨论新增”，总经办另有“手工新增”。

筛选包括状态、优先级、模块、负责人和关键字。选择只更新条件，点击“查询”或“刷新”才请求。桌面使用紧凑表格，窄屏使用保持同字段顺序的卡片。

点击事项打开详情抽屉，显示背景、验收标准、影响路径、依赖、负责人、分支、PR、证据、冲突和事件历史。

## AI 交互

讨论结果显示为可编辑结构化草稿。只有总经办点击“确认写入研发待办”才调用新增 API。未配置或禁用时跳到“数据中心 → AI 大模型”，只保留未提交需求描述；超时和限流在当前页重试。

## 状态

- 加载：骨架，禁用重复提交。
- 空数据：解释当前筛选无结果，可清除筛选。
- 错误：保留上一份可信列表并允许重试。
- 无权限：保留只读内容，服务端拒绝写入。
- 版本冲突：要求刷新，不覆盖当前输入。
- 范围冲突：显示冲突编号、负责人和分支，禁用认领。

所有交互支持键盘、焦点归还、可感知错误和 WCAG AA 对比度。钉钉 WebView 不依赖悬停。
