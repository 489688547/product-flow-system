# 抖音 Ego 唯一采集通道 PRD

## 文档状态

- 研发待办：`DEV-000019`
- 负责人：周荣庆
- 最近更新：2026-08-04

## 背景

公司当前有效抖店登录态位于 Ego，但 `dedicated` 采集模式启动的是独立 Google Chrome。该 Chrome
未登录时，罗盘页先显示空壳，约 15 秒后才跳到登录页；现有 12 秒检查窗口会提前把它误报为页面
结构变化。结果是用户看到错误诊断，反复重试也无法复用真正有效的 Ego 登录态。

## 用户目标

数据管理员从公司平台触发一个已登记店铺的抖音日事实任务后，任务只在 Ego 的固定店铺空间中执行。
Ego 不可用、未登录或店铺不一致时停止并给出准确人工动作；只有官方文件、归档、解析和阿里云
SQLite 事务全部有证据时才显示成功。

## 业务规则

1. 抖音任务只允许 Ego 执行，运行时不得回退 Google Chrome 或 MV3 扩展。
2. 快麦继续使用现有 Chrome MV3 扩展，不随本事项迁移。
3. 领取抖音任务前必须从抖店登记页面核对稳定 `storeId`，店铺名称只用于展示。
4. 登录、扫码、验证码、滑块和设备验证进入 `waiting_human`，不自动重试；只有公司平台
   `force: true` 明确重排同一任务后，本机保存的同任务检查点才允许重新领取对应 Ego 空间。
5. 加载超时与页面结构变化是两个状态；空白、导航中或等待登录跳转不能标成结构变化。
6. 页面提示“导出完成”不是成功；必须确认文件真实存在、大小稳定并计算内容哈希。
7. 阿里云 ECS/SQLite 是唯一正式写入目标。正式入口未切流时保留本地待上传检查点，不写 D1。
8. 首次真实验证只运行一个店铺的一条 `video_daily`，不得批量排队。

## 验收标准

- Ego 在线且登录正常时，同一店铺单条 `video_daily` 可以走到真实文件落盘、归档和解析。
- 测试复现 0.8 秒空白、15 秒登录跳转时，最终状态是 `DOUYIN_LOGIN_REQUIRED`，不是
  `DOUYIN_PAGE_SCHEMA_CHANGED`。
- Ego 未启动或 CLI 不兼容时返回 `EGO_UNAVAILABLE`，进程列表中不新增 Google Chrome。
- 店铺管理页识别到的 `storeId` 与任务不一致时，不打开取数页、不下载、不上传。
- 正式 base URL 不是已确认的阿里云入口时，Ego 正式模式 fail closed；本地探针仍可完成到
  `pending_upload`。
- 快麦扩展测试、网页采集专项、完整质量门禁全部通过。

## 非目标

- 本事项不完成 ICP 备案、DNS、HTTPS、钉钉回调或 ECS 公网切流。
- 不自动处理抖店凭据和人工验证。
- 不接入巨量千川，不重构快麦 Provider，不新增第二套服务端任务队列。
