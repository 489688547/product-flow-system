# 抖店罗盘经营数据采集任务

## 执行规则

- 每项先写失败测试并确认失败原因，再实现最小代码。
- 一次只推进一个共享边界，Kuaimai 兼容测试必须持续通过。
- 不使用子代理；在当前工作树按计划连续执行。
- adapter 未完成真实样本验收前不得显示“已接通”。

## 任务

- [x] 确认范围和设计
  - 输出：店铺、商品、直播、短视频昨天数据；官方下载优先；首版不补历史。
  - 验证：用户确认设计提案。
- [x] 固化治理、ADR、integration 与环境能力
  - 输出：旧凭据登录保持退役、已登录 Chrome 只读采集进入 `integrating`，登记 D1 表与展示策略。
  - 失败测试：缺少 ADR、路径影响或环境模块时治理检查失败。
- [x] 扩展 store-scoped 网页采集控制面
  - 输出：Douyin 四资源、storeId job/cursor、目标环境版本、稳定错误和日计划。
  - 失败测试：不同店铺任务冲突或未知字段被接受时失败。
- [x] 实现标准经营事实与批次 API
  - 输出：批次安全提交、四类事实表、只读查询、质量和派生率。
  - 失败测试：未完成批次可见、缺失值补零、业务数据库绕过或旧环境版本写入时失败。
- [x] 实现 Douyin 文件解析与本机 processor
  - 输出：安全样例 fixtures、四资源字段映射、日期/店铺/行数校验、原始归档和 ingest。
  - 失败测试：未知格式、错日期、缺字段、重复文件或敏感字段进入 payload 时失败。
- [x] 实现 Douyin MV3 adapter
  - 输出：固定 host/page/action、下载、`store_daily` 安全读数、登录与人工验证状态。
  - 失败测试：远端 URL/selector、未知 task 字段、任意页面内容或未登记 host 被接受时失败。
- [ ] 抽取通用 orchestrator processor
  - 输出：Kuaimai 与 Douyin 共用任务执行，支持 `downloaded`/`captured`，保持原有重试、游标、通知。
  - 失败测试：采集结果未入库却完成任务、失败无同步记录或 Kuaimai 回归时失败。
- [ ] 接入数据接入和数据同步 UI
  - 输出：真实 readiness、四资源执行记录、异常优先和人工恢复；巨量千川仍未接入。
  - 失败测试：显示虚假成功、筛选自动请求、错误无恢复动作或窄屏溢出时失败。
- [ ] 完成昨天真实验收
  - 输出：已登录店铺四资源的真实结果、selector/report version、原始归档和 D1 查询证据。
  - 验证：成功资源有完成批次，失败资源有安全错误和可执行恢复动作。
- [ ] 完成全量门禁和 GitOps 发布
  - 输出：全量检查、PR、main 合并、Cloudflare Git 部署、生产 API/UI 与插件复核。
  - 验证：Definition of Done 和 production readiness 全部通过。
