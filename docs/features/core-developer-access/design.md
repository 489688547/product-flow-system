# 核心开发人员本地数据访问设计书

## 用户任务

核心开发人员把总经办交付的一个文件放到固定目录，然后在任意 fork 中执行标准启动
命令，使用本地代码访问完整生产业务数据。

## 信息层级

- 主信息：当前是核心开发模式、正在使用生产真实数据、当前个人身份。
- 辅助信息：文件路径、生产 API 状态、Token 到期时间。
- 低频信息：撤销、重新签发和沙箱切换说明。

## 页面结构

复用现有本地线上模式横幅，不新增设置页面。横幅固定出现在已认证应用内容之前；登录
页或 API 不可用时展示明确错误，不显示 Token。

## 交互流程

`npm start` 自动检测文件。有效时进入核心开发模式；不存在时进入沙箱；存在但无效时
停止并说明文件问题，不能静默降级造成环境误判。开发人员可显式运行
`npm run start:sandbox` 强制使用本地数据。

## 组件复用

复用现有本地环境提示、认证 Provider 和 API 错误呈现。权限判断、Token 注入和 Origin
限制属于服务端/启动器职责，不进入 React 组件。

## 新增组件

不新增共享 UI 组件。平台能力结论为“扩展现有生产数据访问中间件和本地启动器”。

## 页面状态

- 加载：显示正在连接正式 API。
- 空数据：按生产 API 原始业务空状态展示。
- 错误：区分文件缺失、权限错误、Token 过期和正式 API 不可用。
- 无权限：说明联系总经办重新签发个人文件。
- 成功：横幅显示个人姓名和生产真实数据模式，不显示凭据。

## 响应式与钉钉 WebView

本功能面向本地笔记本浏览器；复用横幅需在 390px 宽度换行且不遮挡内容。钉钉
WebView 不读取本地开发文件，线上登录流程不变。

## 交互文案

- `核心开发模式 · 生产真实数据`
- `当前本地代码正在访问线上业务数据，操作会立即生效并记录到你的身份。`
- `开发权限文件无效或已撤销，请联系总经办重新签发。`

## 无障碍

横幅使用 `role=status`，不依赖颜色表达生产环境；错误使用 `role=alert`。现有键盘和
焦点顺序不变。

## 视觉验收

检查 1440、900、640 和 390px 的横幅、身份、错误状态与页面滚动；确认生产模式和
本地沙箱文案不会混淆。
