# 采集器双模式执行 PRD

## 文档状态

- 状态：已评审
- 研发待办：`DEV-000017`
- 负责人：数据采集平台
- 最近更新：2026-07-30

## 背景与问题

公司现有快麦、抖店网页采集已经具备 Provider、店铺、资源、业务日期、任务租约、检查点、
原始文件归档、标准事实入库和同步记录，但正式适配器仍以代码固定页面动作。平台页面变化或新增
临时取数需求时，必须修改代码、发布采集器并重新验收，探索速度较慢。

EasySpider 的源码证明版本化任务图、变量、条件、循环、多候选选择器和本机脚本可以降低网页自动化
试验成本。本项目不复制 EasySpider 源码，也不引入第二套 Electron/Python/Selenium 控制面，而是在
现有公司 Mac Runner 上增加内部实验模式。正式模式继续保护经营事实；实验模式允许总经办和数据
管理员使用更自由的 JavaScript、Python 和系统命令验证页面与文件处理方案。

项目即将迁移到阿里云。网页登录态和 Chrome Profile 继续保留在公司 Mac；任务、API、数据库、日志
和告警从当前 Cloudflare 控制面迁到阿里云时，不得要求重写 Provider 适配器或迁移浏览器登录态。
阿里云在集成注册表中仍为 `integrating`，本功能不能把迁移准备描述为已经接通。

## 目标

1. 在现有网页采集任务上增加 `formal` 与 `experimental` 两种执行模式。
2. 使用版本化任务图描述浏览器动作、本机脚本、条件、循环、变量和文件处理。
3. 实验结果默认标记为 `untrusted`，未经明确校验和发布不得覆盖正式经营事实。
4. Runner 只依赖稳定 HTTP 契约，不识别 Cloudflare D1、阿里云数据库或业务库绑定。
5. 保持现有快麦、抖店正式采集、任务租约、检查点、同步记录和受控入库兼容。

## 非目标

- 不复制或修改 EasySpider 的 AGPL 源码。
- 不在首期建设完整的可视化拖拽编排器。
- 不在本功能中完成阿里云 ECS、数据库或 OSS 的生产迁移。
- 不让实验执行器直接连接正式 D1、SQLite、PostgreSQL 或其他业务数据库。
- 不把验证码破解或反检测默认启用；它们只能作为有审计的实验模板选项。

## 用户与权限

| 角色 | 查看模板与运行 | 执行正式模板 | 编辑和执行实验模板 | 发布正式版本 |
| --- | --- | --- | --- | --- |
| 总经办 | 允许 | 允许 | 允许 | 允许 |
| 数据管理员 | 允许 | 允许 | 允许 | 允许 |
| 运营人员 | 允许授权范围 | 允许授权范围 | 不允许 | 不允许 |
| 公司 Mac Runner | 仅领取设备授权任务 | 按任务执行 | 按任务执行 | 不允许 |

服务端从公司会话读取操作者身份，不接受客户端提交创建人、修改人或审批人。Runner 使用登记设备
Token 领取短期签名执行包，不能自行选择模板版本、数据环境、数据库或正式入库目标。

## 当前流程

1. 云端生成固定 Provider、店铺、资源和业务日期任务。
2. 公司 Chrome 扩展或专用浏览器执行代码登记的页面短动作。
3. 公司 Mac 等待下载、归档、解析、校验并通过受控 API 上传标准事实。
4. 服务端验证租约、目标环境、幂等和完整批次后写入正式数据库。
5. 新页面或临时需求需要修改 Provider 代码并重新发布。

## 目标流程

1. 总经办或数据管理员创建 `experimental` 模板草稿并保存不可变版本。
2. 服务端生成绑定模板版本、内容哈希、Runner 和有效期的签名执行包。
3. 公司 Mac 在现有 Profile 中执行浏览器动作，在固定工作区运行 Python 或系统命令。
4. 每一步保存检查点、耗时、安全输出和文件哈希；重启后从最后安全阶段恢复。
5. 实验结果写入本机 SQLite 并标记 `untrusted`，通过字段、日期、店铺、行数和样本校验后成为
   `validated`。
6. 管理员把已验证模板发布为新 `formal` 版本；以后只有该正式版本的完整成功批次可产生
   `trusted` 事实。

## 业务规则

1. 模板由稳定 `templateId + version` 标识；已保存版本不可覆盖，修改必须生成新版本。
2. 执行模式只能是 `formal` 或 `experimental`，运行中不得切换。
3. 实验模板允许顺序、条件、循环、变量、重试、等待、多候选选择器、页面 JavaScript、
   本机 Python、系统命令和文件下载。
4. 每个步骤必须声明超时；模板同时声明总超时、最大输出、最大子进程数和固定工作目录。
5. 本机命令超时后必须终止完整进程树，不能只结束父进程。
6. 实验结果只能是 `untrusted` 或 `validated`；只有已发布正式模板可生成 `trusted`。
7. 可选字段缺失保存 `null` 并降低覆盖率；必填字段缺失使批次失败，不允许自动补零。
8. 正式批次失败时保留上一可信批次；不得用实验结果、部分结果或默认值覆盖。
9. 登录、验证码、扫码、滑块和设备验证进入 `waiting_human`，不消耗自动重试次数。
10. 浏览器登录态、Cookie、Token、验证码、完整页面正文和客户数据不得进入模板、任务或云端日志。

## 数据定义

### 模板

| 字段 | 含义 |
| --- | --- |
| `templateId` | 稳定模板 ID |
| `version` | 从 1 递增的不可变版本 |
| `mode` | `formal` 或 `experimental` |
| `providerId` | 已登记 Provider |
| `profileId` | 公司 Mac 本地 Profile 引用，不包含本机路径 |
| `timeoutSeconds` | 整体执行上限 |
| `limits` | 输出、子进程、文件和循环上限 |
| `steps` | 版本化任务图 |
| `contentHash` | 模板规范化内容哈希 |
| `status` | `draft`、`published`、`archived` |

### 运行

| 字段 | 含义 |
| --- | --- |
| `runId` | 单次执行稳定 ID |
| `templateId/version` | 本次锁定模板版本 |
| `runnerId` | 服务端分配的公司 Mac |
| `businessDate` | `Asia/Shanghai` 业务日期 |
| `status` | `queued`、`running`、`waiting_human`、`failed`、`completed` |
| `trustLevel` | `untrusted`、`validated`、`trusted` |
| `checkpoint` | 最后安全步骤与恢复信息 |
| `artifactHashes` | 原始文件与结果文件哈希 |
| `quality` | 覆盖率、必填字段、店铺、日期、行数和样本校验 |

## 异常与边界

- 模板哈希、签名或版本不一致：拒绝执行并返回 `COLLECTOR_TEMPLATE_HASH_MISMATCH`。
- 用户无实验权限：返回 `COLLECTOR_TEMPLATE_ACTION_DENIED`。
- JavaScript、Python 或命令超时：终止步骤或进程树并返回 `COLLECTOR_SCRIPT_TIMEOUT`。
- 输出超过上限：停止收集输出并返回 `COLLECTOR_OUTPUT_LIMIT_EXCEEDED`。
- 检查点不属于当前模板版本：拒绝恢复并返回 `COLLECTOR_CHECKPOINT_INVALID`。
- 实验结果请求正式写入：拒绝并返回 `COLLECTOR_RESULT_UNTRUSTED`。
- Runner 离线：任务保持可恢复状态并显示设备、最后心跳和恢复动作。
- 阿里云未完成接入：继续使用当前 Cloudflare 控制面，不能自动回退到未登记服务地址。

## 验收标准

1. 现有快麦、抖店正式采集聚焦测试和完整回归全部通过。
2. 一个实验模板能完成打开登记页面、执行 JavaScript、下载文件、运行 Python 解析和系统命令。
3. 条件、循环、变量、多候选选择器、超时和失败分支都有契约测试。
4. Runner 或 Chrome 重启后能从同一模板版本的最后安全检查点恢复。
5. 实验结果不会自动写入正式事实；未发布模板无法产生 `trusted`。
6. 模板执行包被修改、过期或分配给错误 Runner 时拒绝执行。
7. Cloudflare 与阿里云服务端实现可以复用同一 HTTP、错误码和存储适配器契约测试。

## 上线与回滚

- 首期通过功能开关启用实验模式；默认关闭，不改变现有正式任务领取。
- 先在指定公司 Mac 上使用不含客户敏感数据的模板完成本机验收。
- 实验模式异常时关闭开关，正式采集器继续使用现有任务和 Provider 适配器。
- 模板、运行记录和本机实验 SQLite 不参与正式事实回滚；关闭实验模式不删除历史审计。
- 阿里云切换单独由其迁移事项执行；本功能只保证 Runner 与服务端之间的稳定协议。
