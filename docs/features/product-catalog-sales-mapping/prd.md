# 商品主数据销售编码治理 PRD

## 问题

商品主数据页面把快麦组合品的组成商品误当成组合品自身 SKU。真实目录中的组合品由一个或多个组件 SKU 及数量构成，不一定拥有独立库存 SKU。当前页面因此把正常组合品误报为“缺少库存单位”，并把销售事实中未匹配的“编码 × 平台”聚合行描述成未知商品，用户无法查看或处理。

## 目标

1. 用“单品规格”和“组合品组成”两个模型展示商品结构。
2. 不再因为组合品没有自身库存 SKU 而判定档案不完整。
3. 将未匹配销售事实按销售编码聚合，优先引导重新获取完整 ERP 商品档案；只有确认属于历史销售别名时，才允许有权限的用户关联到一个商品。
4. 关联只补充销售事实归属，不修改快麦商品、SKU 或组件数据。

## 非目标

1. 本期不实现 Chrome 商品采集、自动登录或快麦页面读取。
2. 本期不发布线上，也不改写生产 D1。
3. 本期不根据商品名称、编码长度或前缀推断组合关系。
4. 本期不把组件销量自动归属为组合品销量。

## 数据定义

- 商品编码：快麦主商品的商家编码，用于识别商品，不等同于库存 SKU。
- 单品规格：单品可销售、可库存的 SKU。
- 组合品组成：组件 SKU 编码、数量及可选组件商品关系。
- 未归属销售编码：销售事实中的 `code` 无法通过商品 SKU 或已启用人工映射唯一归属到商品。界面称为“销售数据未找到商品”，避免让用户误以为所有编码都需要人工匹配。
- 未归属汇总行：同一销售编码在一个平台上的聚合行。
- 人工映射：销售编码到商品 ID 的版本化、可撤销关系；不得修改 ERP 商品档案。

## 业务规则

1. 单品没有规格时标记“缺少规格”；组合品只有在没有组成关系时标记“缺少组成关系”。
2. 组合品在界面与筛选中的分类固定为“组合品”，ERP 原始分类只保留为来源字段，不参与组合品展示分类。
3. 组合品成本只按当前目录中各组成 SKU 的单位成本乘组件数量汇总，不使用组合品自身 SKU 成本，也不优先使用组成关系中的历史成本快照；任一组件成本或对应商品不明确时显示“成本不完整”，不得按零元计算。
4. 未匹配数量同时提供：
   - 未匹配销售编码数；
   - 编码 × 平台汇总行数。
5. 未匹配明细按销售编码展示标题、平台、销售数量、净销售额和最新业务日期。
6. 出现未匹配编码时，主操作必须是重新导入或采集完整的 ERP 商品、SKU 和组合关系；导入成功后自动重新查询当前日期范围并重算归属。
7. 人工映射是二级兜底，只用于已确认的历史销售别名；目标必须是当前有效商品，且一个销售编码只能有一个启用映射。
8. 保存或撤销映射要求商品目录编辑权限，并写入无秘密审计记录。
9. 聚合时优先使用 SKU 唯一匹配；SKU 冲突时失败关闭，不使用人工映射掩盖目录冲突。
10. 映射保存后重新查询当前日期范围，更新商品销量和未匹配指标。
11. 组合品组件编码只描述出库消耗：若销售编码只存在于组合品组件中、没有对应单品商品档案，必须提示“子 SKU 缺少单品档案”，不得把销量自动归到组合品。

## 用户流程

1. 用户进入商品主数据，先看到商品、有销量商品、ERP 商品数据完整性提醒和最近同步状态。
2. 有未归属销售编码时，用户点击“从 Chrome 重新获取商品”，由采集器获取最新完整商品文件。
3. 导入成功后页面自动刷新当前经营日期范围；已有 SKU 同码自动归属，不要求人工处理。
4. 用户点击完整性指标查看仍未解决的编码、平台、数量、净销售额和最新日期。
5. 只有确认编码是已有商品的历史销售别名时，用户展开二级手工关联并保存。
6. 用户可在已确认的销售别名中撤销人工映射；撤销后该编码重新进入未归属列表。

## 验收标准

1. 页面不显示“快麦已落库 · 订单创建时间 · 默认不含其它”和顶部“库存单位”指标。
2. 表格使用“SKU / 组成”“成本”：单品显示自身 SKU，组合品显示子 SKU 和每套数量；不再使用“SKU / 库存单位”“ERP 成本”。
3. 有组成关系的组合品不会因为 `skus=[]` 被判定为档案问题。
4. 组合品行可看到组成数量，详情可看到组件编码和数量。
5. 未匹配警告显示唯一销售编码数，并说明对应的编码 × 平台行数。
6. 点击警告打开可操作明细，而不是跳转到同步记录。
7. 无编辑权限用户只能查看；编辑权限、目标校验、冲突和撤销均有服务端测试。
8. 所有写入在本地沙箱验证，生产数据库保持不变。
9. 商品/SKU 档案已有同码时自动归属；组件独有编码显示缺少单品档案，不要求用户把它关联到组合品。
10. 组合品分类固定显示“组合品”，筛选“组合品”能命中全部组合品。
11. 组合品成本严格使用当前组成 SKU 成本乘数量汇总；组件缺成本时列表和详情都显示“成本不完整”。
12. 未归属销售提醒的主操作更新 ERP 商品档案，导入后自动重新匹配；手工关联默认收起。
