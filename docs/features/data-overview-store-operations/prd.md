# 数据总览店铺经营数据 PRD

## 文档状态

- 状态：已评审
- 负责人：产品负责人
- 最近更新：2026-07-24

## 背景与问题

抖店罗盘的店铺经营事实（`store_daily`、`product_daily`、`live_daily`、`video_daily`）已由公司 Mac 采集入库，并有 `GET /api/platform/v1/commerce-facts` 查询接口，但前端没有任何页面消费它——采集到的店铺经营数据无处可看。数据总览当前只展示快麦 ERP 销售的公司级汇总，没有店铺维度，运营无法在总览里按店铺查看当日经营表现与商品排名。

## 目标

1. 数据总览新增「店铺经营数据」区，支持在已登记的抖店店铺之间切换。
2. 以最新可信业务日为准，展示店铺每日汇总 KPI（GMV、成交订单、成交人数、客单价、曝光点击率、退款率），并给出同比昨天的升降方向与比例。
3. 展示当日重点商品 Top 10（按成交金额降序），每个商品带同比昨天 GMV 升降。
4. 展示当日直播与短视频经营摘要。

## 非目标

- 不新增经营事实表或采集任务；仅读取已登记资源。
- 不在前端复制口径公式；同比只做相邻两业务日的简单对比，公司级统一 KPI 仍走共享口径。
- 不替代电商店铺运营 App 的经营驾驶舱；总览只做只读概览。

## 业务规则

- 仅展示 `provider=douyin-ecommerce` 且 `status=connected` 的店铺。
- 同比对象为经营事实中最新业务日紧邻的前一日；缺前一日或前一日为零时该项标记为不可比，不补 0。
- 退款率越低越好，方向为「下降」时判为正向；其余指标越高越好。
- 经营事实查询受 `authorizeWebCollectionView` 限制；无权限账号（403）时该区优雅降级为提示，绝不影响总览其余部分。

## 验收标准

- 进入数据总览，出现「店铺经营数据」区并默认选中一个店铺；切换店铺后数据随之刷新。
- 店铺每日 KPI、商品 Top 10 与直播/短视频摘要与抖店罗盘口径一致，同比箭头方向与比例正确。
- 无已登记店铺、店铺当日无数据、无权限、读取失败四种状态均有明确空/错/降级提示。
