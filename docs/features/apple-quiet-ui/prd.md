# Apple 克制风格全局 UI/UX 重构

## 问题

现有页面功能完整，但全局外壳、共享控件和数据总览的视觉层级偏平均，导航密度较高，不利于老板快速定位重点。

## 目标

- 统一全局外壳、导航、按钮、页头、弹窗和筛选控件。
- 以数据总览作为首个标杆页，突出核心指标和经营趋势。
- 第二阶段把导航从长列表改成“业务 App → 当前功能”的两级结构。
- 公司首页先展示今天需要拍板、协调和升级的事项；产品总览先展示风险与下一步动作。
- 保持全部业务逻辑、数据口径、权限和外部系统行为不变。

## 非目标

- 不重做所有业务页面的业务表单。
- 不新增第二套组件库。
- 不修改 API、数据库、环境配置或外部平台集成。

## 验收标准

1. 全局界面采用冷灰、实体表面和克制层级；无大面积玻璃效果。
2. Bubble 只用于选中、状态、日期和主操作。
3. 数据总览的核心指标形成连续指标组，趋势为视觉重点。
4. 键盘焦点、禁用、加载、错误和减少动效状态清晰。
5. 现有业务测试与完整项目门禁通过。
6. 桌面端始终只显示业务 App 和当前 App 的功能，不再同时展开全部功能。
7. 公司首页首屏可直接看见待决策、个人待办、经营风险和产品协同数量。
8. 产品总览先呈现风险与待办，再呈现流程中的产品，入口名称和动作结果清楚。
