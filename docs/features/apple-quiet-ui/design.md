# Apple 克制风格设计

## 方向

使用 Apple 系统应用式的冷静、实体、低噪声表达。布局保持 Workbench 工作台结构，不使用营销页式大标题、装饰渐变或漂浮玻璃卡片。

## 视觉规则

- 背景为轻微冷灰，侧栏与内容表面使用不透明材质。
- 边框承担主要分组，阴影只帮助浮层和当前操作建立层级。
- 主蓝色仅用于当前导航、主操作、日期范围和关键状态。
- 圆角分为控件、面板、浮层三档；Bubble 不扩散到普通内容卡片。
- KPI 为一个连续指标组，经营趋势占更大空间，平台分布退为次级。

## 交互规则

- 按下立即反馈，位移不超过 1px，不使用弹跳或持续动画。
- 焦点环立即出现，不能只依赖颜色表达状态。
- `prefers-reduced-motion` 下关闭非必要位移和旋转。
- 窄屏保持当前页面上下文，控件不横向溢出。

## 复用

扩展现有 `Button`、`PageHeader`、`Modal`、`FloatingMenu`、日期范围选择器和数据总览组件，不建立并行设计系统。
