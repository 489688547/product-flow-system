# Apple 克制风格设计

## 方向

使用 Apple 系统应用式的冷静、实体、低噪声表达。布局保持 Workbench 工作台结构，不使用营销页式大标题、装饰渐变或漂浮玻璃卡片。

第二阶段把 Workbench 外壳改成两级导航：

- 一级窄轨只表示业务 App，负责快速切换工作域。
- 二级侧栏只显示当前 App 的功能，负责当前工作域内导航。
- 顶部栏显示“当前 App / 当前页面”，全局 AI 和账号动作保留在右侧。
- 页面首屏按“需要处理 → 经营证据 → 完整工作区”组织，不再平均堆叠卡片。

## 视觉规则

- 背景为轻微冷灰，侧栏与内容表面使用不透明材质。
- 边框承担主要分组，阴影只帮助浮层和当前操作建立层级。
- 主蓝色仅用于当前导航、主操作、日期范围和关键状态。
- 圆角分为控件、面板、浮层三档；Bubble 不扩散到普通内容卡片。
- KPI 为一个连续指标组，经营趋势占更大空间，平台分布退为次级。

## 交互规则

- 按下立即反馈，位移不超过 1px，不使用弹跳或持续动画。
- 焦点环立即出现，不能只依赖颜色表达状态。
- `prefers-reduced-motion` 下关闭非必要位移和旋转。
- 窄屏保持当前页面上下文，控件不横向溢出。
- 切换一级 App 后直接进入该 App 的第一个有权限页面，二级功能无需再次展开。
- 移动端一级和二级导航变成两条可横向滚动的实体导航带，保持 44px 触控目标。

## 核心页面

### 公司首页

- 首屏先给四个可行动摘要：待拍板、我的待办、经营风险、产品待办。
- “需要我处理”是主区域，经营地图和完整列表退到下一层。
- 摘要本身是入口，不做只能看的装饰数字。

### 产品总览

- 风险和待办优先于产品列表。
- 流程中的产品作为横向轨道，显示产品、级别、进度和状态。
- 所有摘要均指向明确页面或具体产品阶段。

### 数据中心

- 当前数据健康状态紧邻页头，异常直接进入同步处理。
- 数据中心的八个功能只出现在当前 App 的二级导航，不再占据全局长侧栏。

## 复用

新增共享 `WorkspaceNavigation` 外壳，扩展现有 `Button`、`PageHeader`、`Modal`、`FloatingMenu`、日期范围选择器和数据总览组件，不建立并行设计系统。
